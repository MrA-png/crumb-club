# CRUMB artwork

Original vector character and brand artwork from the supplied website. All SVGs are self-contained, editable, and require no external images. Avatar files include the mood-specific display rules. `mascot-original.svg` has a transparent background. `logo-primary.svg`, `wordmark.svg`, and `icon.svg` form the logo system.

Logo text uses standard local sans-serif names; no font files are included. Use the favicon at `public/icon.svg`, the 180-pixel Apple touch icon, and the 1200 x 630 social image in the parent folder. For animated use, edit `components/brand/Mascot.tsx`, which preserves separate eye, head, wing, crumb, and accessory layers.
