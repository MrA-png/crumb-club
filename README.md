# CRUMB
## Small bird. Big crumb energy.

A complete, original meme-brand landing page: a street-smart pigeon, cream and charcoal typography, acid-lime accents, layered SVG artwork, and interactive storytelling. All website copy is in English.

## Open the working preview

Open **`preview/index.html`** in a modern browser. This file is self-contained: no npm install, external images, CDN, wallet connection, or API key is required. It includes the complete page and working mascot reactions, token dialog, keyboard controls, roadmap, allocation visualizer, avatar downloads, and meme downloads.

Clipboard access depends on the browser's secure-context and permission rules. When unavailable, the interface explains how to copy manually. The preview is intentionally a brand concept, not a live trading application.

## Run the Next.js application

Use Node.js 22 LTS or another compatible version satisfying `package.json`.

```sh
npm install
cp .env.example .env.local
npm run dev
```

Open `http://localhost:3000`. The default configuration deliberately leaves deployment and financial information unannounced. No wallet or account is required to explore the design.

For a release candidate:

```sh
npm run typecheck
npm run lint
npm run build
npm run start
```

Commit the lockfile generated by your successful installation. No fabricated or unverified lockfile is included.

```text

                        Small React/Motion client island

tools/                  Standalone export and reproducible preview QA
tests/                  Playwright tests for the installed Next app
docs/                   Brand notes, deployment checklist, QA results
```

Most page content is rendered as React Server Components. A single client island mounts delegated interactions and uses Motion for React. The standalone preview shares those interaction modules but uses the native Web Animations API instead of loading React or Motion from a CDN. It is a preview of the design and behavior, not proof that a Next.js production build has passed.

The visual design is predominantly custom CSS. Tailwind v4 is configured for theme tokens and further utility-based development. Lucide supplies utility icons; social marks and the mascot are SVG. No emoji icons, font binaries, photographic stock assets, analytics, tracker, or wallet SDK is bundled.

## Configure real deployment data

Copy `.env.example` to `.env.local`. **Every `NEXT_PUBLIC_` value is public and is included in the client build. Never place secrets, seed phrases, private keys, or provider credentials here.** Restart/rebuild after changing configuration.

| Variable | Purpose |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Canonical production HTTPS origin; also enables search indexing metadata. |
| `NEXT_PUBLIC_CHAIN_NAME` | Exact name of the verified deployment network. |
| `NEXT_PUBLIC_CONTRACT_ADDRESS` | Full, independently verified token address for that network. |
| `NEXT_PUBLIC_BUY_URL` | Verified external HTTPS purchase destination. |
| `NEXT_PUBLIC_CHART_URL` | Verified external HTTPS chart destination. |
| `NEXT_PUBLIC_EXPLORER_URL` | Verified HTTPS explorer page for this contract. |
| `NEXT_PUBLIC_X_URL` | Official HTTPS X profile. |
| `NEXT_PUBLIC_TELEGRAM_URL` | Official HTTPS Telegram channel. |
| `NEXT_PUBLIC_DISCORD_URL` | Official HTTPS Discord invitation. |
| `NEXT_PUBLIC_TOKEN_SUPPLY` | Verified, human-readable supply with units. |
| `NEXT_PUBLIC_TOKEN_TAX` | Verified, human-readable tax disclosure. |
| `NEXT_PUBLIC_TOKEN_OWNERSHIP` | Verified, human-readable ownership/permissions disclosure. |
| `NEXT_PUBLIC_METRICS_URL` | Optional HTTPS endpoint satisfying the schema below. |

Invalid, non-HTTPS, or credential-bearing destination URLs are omitted. A contract is only published when both the chain and address are supplied. This is a configuration gate, **not an on-chain verification service**: the operator must validate the actual network, address, token identity, permissions, and destination before publishing them.

A configured buy link opens only after the visitor acknowledges risk. This app sends the visitor to an external venue; it does not submit swaps, sign transactions, custody funds, or deploy a token. Without a verified deployment, buy buttons open the honest prelaunch dialog. Unannounced social and chart buttons explain their status rather than opening invented accounts.

## Optional metrics endpoint

No provider is preselected and no request is made when the endpoint, chain, or contract is missing. Supply an HTTPS JSON endpoint with appropriate CORS. Keep provider credentials in your own backend. A valid response has this shape:

```ts
type MetricsSnapshot = {
  asOf: string;    // ISO timestamp no more than five minutes old
  source: string;  // HTTPS provenance link
  chain: string;   // Exact match with configured chain
  contract: string; // Exact match with configured address
  metrics: {
    holders: number | null;
    marketCap: number | null;   // USD
    liquidity: number | null;   // USD
    members: number | null;
    transactions: number | null;
  };
};
```

All five metric keys must be present. Numbers must be finite, nonnegative, and within the safe numeric range. Holder, member, and transaction counts must be integers. `null` means not published. Future timestamps beyond 30 seconds are rejected. The adapter polls every 60 seconds while visible, aborts slow requests, and removes expired or invalid data instead of displaying replacement figures. The source is linked for inspection. Provenance and schema checks do not independently guarantee that a provider's assertions are true.

The proposed 70/20/5/3/2 token allocation lives separately in `lib/content.ts`. It is explicitly labeled illustrative, not a deployed distribution, lock, vesting schedule, or financial promise. Replace it only after the project has actually approved and disclosed a distribution.

## Export another standalone preview

```sh
npm run preview:export
```

The exporter inherits variables from its shell environment. Next.js loads `.env.local` when the app runs; the separate export script does not automatically read that file. To include deployment data in an export, set the relevant environment variables for the export process. It is safe to export the default unannounced concept with none set.

## Verification

See **`docs/QA.md`** for exact scope and limitations. The supplied standalone preview passed 34 Chromium behavioral/responsive checks, including no page-level horizontal overflow at widths from 320 to 1920 pixels. The dependency-free TypeScript interaction core also passed a strict compiler check.

**The Next.js production build, full dependency-aware typecheck, lint, and Lighthouse score were not verified in the delivery environment because npm registry access was blocked.** No performance score or cross-browser certification is claimed. Run the commands above before deployment.

To run the included Next.js Playwright suite after installation:

```sh
npx playwright install chromium
npm run test:e2e
```

To reproduce the standalone browser QA with Python Playwright:

```sh
python -m pip install playwright
python -m playwright install chromium
python tools/verify-preview.py
```

Set `CHROMIUM_PATH` only when using a separately installed Chromium executable.
